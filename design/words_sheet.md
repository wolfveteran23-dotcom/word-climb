# Words design sheet

Columns:
- id: numeric id
- scrib_name: name as found in Scribblenauts data
- icon: relative path inside Scribblenauts install for icon
- sound: relative path inside Scribblenauts install for sound
- peak_object: identifier for the PEAK prefab or spawn routine
- stamina_cost: integer stamina cost to conjure

Keep numbers small for early levels. Update this sheet while iterating.
