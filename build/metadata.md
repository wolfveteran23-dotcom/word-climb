# Word-Climb

## Status
Draft build only. No local game session or multiplayer test has been started.

## Title
Word-Climb

## Tagline
Conjure Scribblenauts items to climb PEAK's heights

## Description
Word-Climb is a PEAK x Scribblenauts Unlimited mashup. Type words into a small notepad UI to conjure Scribblenauts items (rope, ladder, balloon, etc.) and use them to climb PEAK's cliffs. Each conjure uses stamina; riskier words cost more. Requires your own Scribblenauts Unlimited install; the mod reads words, icons and sounds from your copy at runtime. Multiplayer co-op is supported through PEAK's own multiplayer. Credit: wolfveteran23-dotcom. License: CC BY-NC.
